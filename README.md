# BostonRobotics AdminSystem

เว็บไซต์สำหรับผู้ดูแลหนึ่งคน ใช้ GitHub Pages + Google Apps Script + Google Sheets

## สิ่งที่แก้ไขในรุ่น 2.0

- ใช้ชื่อนักเรียน หลักสูตร และระดับบนหน้ารายการ รหัสอยู่เบื้องหลังและในฟอร์มลงทะเบียนเท่านั้น
- กรองแถวไม่มีรหัส รอข้อมูลทุกชุดก่อนแสดงผล และแยกสถานะไม่มีข้อมูลออกจากโหลดไม่สำเร็จ
- รับวันที่ dd/MM/yyyy และ yyyy-MM-dd ใช้เวลา Asia/Bangkok
- คำนวณชั่วโมงเมื่อถึงเวลาจบนัด คำนวณใหม่จากตารางทุก 30 วินาทีและเมื่อเปิดเว็บ ไม่หักซ้ำ
- ตรวจเวลาซ้อนที่ API ภายใต้ lock แสดงนักเรียนทุกคนพร้อมหลักสูตร ระดับ และเวลา ให้ยืนยันเรียนห้องเดียวกัน
- ยืนยันใหม่เมื่อข้อมูลที่ซ้อนเปลี่ยนไป และป้องกันการสร้างนัดเดิมซ้ำตรงวันเวลาใน enrollment เดียวกัน
- เตือนก่อนจัดนัดตรงวันหยุด การบันทึกวันหยุดไม่ยกเลิกนัดเดิมอัตโนมัติ
- เก็บหมายเหตุเมื่อแก้ไขข้อมูล ไม่เปลี่ยนวันที่ลงทะเบียนเดิม
- ตรวจรหัสผ่านฝั่ง API ทุกการอ่าน/เขียน session อยู่ในหน่วยความจำของหน้าเว็บเท่านั้น

## อัปเดต Google Apps Script (ต้องทำให้ครบเพื่อเปิดใช้งาน)

1. เปิด Google Sheets เดิม แล้วเลือก **ส่วนขยาย > Apps Script**
2. สำรอง Code.gs เดิม แล้วแทนเนื้อหาด้วย [apps-script/Code.gs](apps-script/Code.gs) และบันทึก
3. ใน **Project Settings > Script properties** เพิ่ม `ADMIN_PASSWORD` เป็นรหัสผ่านใหม่อย่างน้อย 12 ตัวอักษร ตั้งใน Google โดยตรง ไม่ส่งรหัสผ่านในแชตหรือใส่ใน GitHub
4. ตั้ง Time zone เป็น `Asia/Bangkok` (หรือใช้ appsscript.json ที่ให้มา โดยรักษาการตั้งค่าอื่นของโปรเจกต์เดิม)
5. เลือก **Deploy > Manage deployments > deployment เดิม > Edit > Version: New version > Deploy** เพื่อรักษา URL /exec เดิม
6. ใช้สิทธิ์ Execute as เจ้าของเดิม และรักษาการเข้าถึง deployment เดิม API รุ่นนี้บังคับรหัสผ่านแม้ URL จะเรียกได้สาธารณะ
7. เปิด URL /exec เดิมต่อด้วย `?action=getHealth` ต้องได้ `success: true`, `version: "2.0"`, `configured: true`
8. เปิดเว็บไซต์ GitHub Pages แล้วเข้าสู่ระบบด้วยรหัสผ่านที่ตั้งไว้ และตรวจว่านักเรียน หลักสูตร การลงทะเบียน ตารางเรียน วันหยุดแสดงครบ

**เพียงบันทึก Code.gs ไม่ได้อัปเดต deployment ที่เผยแพร่ ต้องเลือก New version ด้วย**

หากสร้าง deployment ใหม่ ต้องแก้ `API_URL` ใน `js/app.js` ให้เป็น URL ใหม่ และปิด deployment เก่าที่เปิดข้อมูลโดยไม่มีรหัสผ่าน

เว็บไซต์รุ่นใหม่จะอ่านข้อมูลเท่าที่อ่านได้จาก API เก่าและปิดปุ่มบันทึกจนกว่าจะอัปเดต backend สำเร็จ เพื่อป้องกันการบันทึกผ่านโค้ดคนละรุ่น

## การเข้าถึงข้อมูล

รหัสผ่านตั้งใน Script properties เท่านั้น Session หมดอายุไม่เกิน 6 ชั่วโมง (Google Cache อาจหมดเร็วกว่านั้น) หรือเมื่อออกจากระบบ/เปลี่ยนรหัสผ่าน รีเฟรชหน้าเว็บต้องเข้าสู่ระบบใหม่ ล็อกการลองรหัสผ่านผิดเกิน 5 ครั้งภายในหนึ่งนาที

สิทธิ์แชร์ไฟล์ Google Sheets แยกจากรหัสผ่านเว็บนี้ หากแชร์ชีตเป็นสาธารณะ ผู้ที่เปิดชีตยังอ่านได้ ควรตั้งเป็น Restricted สำหรับบัญชีเจ้าของตามการใช้งานจริง

## ตรวจสอบในเครื่อง

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้ง dependencies

```sh
npm test
npm run preview
```

ทดสอบ UI แบบไม่แตะข้อมูลจริง:

```sh
node tools/preview.cjs --demo
```

เปิด http://127.0.0.1:4173 และใช้รหัสทดสอบ `test-only-password-123` (ใช้กับ fixture ในเครื่องเท่านั้น ไม่มีใน backend จริง)

ชุดทดสอบครอบคลุมรูปแบบวันเวลา เขตเวลา หักชั่วโมง การยืนยันเวลาซ้อน แก้ไขตัวเอง นัดต่อเนื่อง การรักษาข้อมูลเดิม และการบังคับสิทธิ์ API การทดสอบกับ mock Apps Script ไม่ทดแทนการตรวจหลัง deployment จริง
