อัปเดตใบเสร็จ 3.0.2
รวมหน้าตาใบเสร็จจาก HTML ที่สถาบันส่งมา พร้อมตราประทับและลายเซ็นต้นฉบับ
เพิ่มคอลัมน์ ใบเสร็จรับเงิน ถัดจาก จัดการ ในแท็บลงทะเบียนเรียน
รายการชำระแล้วกดออกใบเสร็จได้ เติมชื่อนักเรียน ผู้ปกครอง หลักสูตร และ Level อัตโนมัติ ราคายังกรอกเอง
เมื่อมีใบเสร็จเชื่อมด้วย EnrollmentID แล้ว ปุ่มจะเปิดใบเดิม ใบเสร็จเก่าที่ไม่มี EnrollmentID ยังไม่สามารถจับคู่ให้อัตโนมัติได้
วิธีติดตั้ง: แตก ZIP แล้วอัปโหลด index.html พร้อมโฟลเดอร์ js, css, assets ไปทับตำแหน่งเดิมที่หน้าแรกของ GitHub repository กด Commit changes รอ GitHub Pages อัปเดต จากนั้นกด Ctrl+Shift+R ที่เว็บ
ไม่ต้องแก้ Code.gs หรือ Deploy ใหม่ และแพตช์ไม่รวม finance-config.js จึงไม่ทับ URL การเงินที่ตั้งไว้
ทดสอบด้วยข้อมูลจำลองเท่านั้น ไม่มีการบันทึกรายการจริงลงชีต
