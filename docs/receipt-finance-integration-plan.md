# ขอบเขตระบบการเงินและใบเสร็จ

อัปเดต 4 ตุลาคม 2569: ผู้ใช้ให้สร้างระบบใหม่โดยไม่ใช้ Code.gs การเงินเดิม ยืนยันให้ใบเสร็จสร้างรายรับอัตโนมัติ ป้องกันซ้ำ และไม่ใช้รหัสผ่านทั้งสองแท็บ

สร้างหน้าเว็บและ API ใหม่เรียบร้อยในชุด 3.0.0 ยังไม่เผยแพร่หรือเขียนข้อมูลจริง

รายละเอียดฐานข้อมูล ผลลัพธ์ คอลัมน์ที่จะเพิ่ม วิธีติดตั้ง และข้อจำกัด อยู่ที่ [finance-setup.md](finance-setup.md)
