# ระบบการเงินและใบเสร็จ 3.0.0

สร้างใหม่โดยไม่ใช้โค้ด Apps Script การเงินเดิม หน้าเว็บมีแท็บรายงานการเงินและแท็บใบเสร็จล่างสุด ทั้งสองแท็บไม่มีรหัสผ่านตามคำขอ

## สถานะ

ชุดนี้เป็นไฟล์ในเครื่อง ยังไม่ได้อัปโหลด GitHub หรือเผยแพร่ Apps Script ใหม่ และยังไม่แก้ข้อมูลการเงินจริง การทดสอบใช้ข้อมูลจำลองทั้งหมด

## ติดตั้ง

1. สร้าง Apps Script **โปรเจกต์ใหม่** แล้วใส่ไฟล์ `apps-script/finance/Code.gs` เป็น Code.gs ของโปรเจกต์ใหม่ ไม่ใส่แทน Code.gs ของตารางเรียน
2. ใช้บัญชีที่มีสิทธิ์แก้ไขฐาน RoboDB และ Receipt System Database ที่ระบุในโค้ด ตรวจ ID ก่อนเผยแพร่
3. Deploy > New deployment > Web app ให้ทำงานในนามเจ้าของ และตั้งการเข้าถึงให้ตรงกับการใช้งานแบบไม่มีรหัสที่ต้องการ ตัวเลือก Anyone จะทำให้ผู้มี URL อ่านและบันทึกข้อมูลผ่าน API นี้ได้
4. คัดลอก URL ที่ลงท้าย `/exec` ลง `js/finance-config.js` ในค่า `apiUrl` แล้วนำ index.html, โฟลเดอร์ js, css, assets ขึ้นเว็บเดิม อีกทางหนึ่ง ตั้ง URL ในแท็บรายงานการเงิน > ตั้งค่าการเชื่อมต่อ แต่ทางนี้จำค่าเฉพาะเบราว์เซอร์
5. เปิดเว็บ เลือกแท็บรายงานการเงิน ตรวจยอดเทียบกับชีตจริงก่อนเริ่มออกใบเสร็จ อย่าออกใบเสร็จทดสอบในฐานจริง

API ตารางเรียนยังเป็นตัวเดิม การเชื่อมต่อการเงินแยกอิสระ ระบบไม่ย้ายข้อมูลหรือรวมชีตสำรอง

## ข้อมูลและคอลัมน์

- อ่านการเงินจาก `Transactions` ใน RoboDB เท่านั้น เก็บชื่อคอลัมน์เดิมทั้ง 15 คอลัมน์ ไม่รวม Transactions_Backup
- อ่านใบเสร็จจาก `Data1` ฐาน Receipt System Database ใช้ 14 คอลัมน์เดิม
- เมื่อบันทึกใบเสร็จใหม่ครั้งแรก โค้ดจะเพิ่มหัวคอลัมน์ท้ายตารางที่ยังไม่มี: **O: RequestID, P: StudentID, Q: EnrollmentID, R: Level, S: PaymentMethod, T: TransactionID** หากมีคอลัมน์อื่นเพิ่มไว้ก่อนแล้ว จะต่อท้ายตำแหน่งจริงโดยไม่ทับของเดิม
- ณ วันที่จัดชุดไฟล์นี้ **ยังไม่ได้เพิ่มคอลัมน์เหล่านี้ลงชีตจริง**
- ตารางเรียนยังใช้ฐาน BostonRobotics_CalendarV2 ID ที่ลงท้าย `W3gQFSI` ตามที่แจ้ง ไม่มีการเดาราคาจากชั่วโมงเรียน ต้องระบุจำนวนเงินรับจริง

## การนับยอดและใบเสร็จ

- นับเฉพาะรายการ `active` ประเภท income/expense วันที่ถูกต้อง และไม่เกินวันนี้ตามเวลาไทย
- รวมเงินโดยใช้หน่วยสตางค์ ป้องกันความคลาดเคลื่อนทศนิยม และไม่นับรหัสรายการซ้ำ
- ยอดสะสมเริ่มจากรายการแรกที่บันทึก หากข้อมูลไม่ครบตั้งแต่วันเปิดสถาบัน ยอดนี้ยังไม่ใช่ยอดตลอดอายุสถาบันที่ครบถ้วน
- ส่วนต่างเงินเข้า–ออกเป็นข้อมูลกระแสเงินสด ไม่ใช่กำไรทางบัญชี แสดงข้อเสนอเบื้องต้นจากช่องว่างรายรับและหมวดรายจ่ายสูงสุด
- ใบเสร็จใหม่ใช้เลข `BR-ปี-N001` เป็นต้น เพื่อแยกชุดเลขจากระบบเดิม ยังคงอ่านใบเสร็จเก่าได้
- ใบเสร็จที่บันทึกใหม่สร้างรายรับหนึ่งรายการ อ้างอิง ReceiptNo และ TransactionID ไม่สร้างรายรับย้อนหลังจากใบเสร็จเก่าโดยอัตโนมัติ เพราะอาจมีการลงรายรับไว้แล้ว
- ถ้าการเขียนฐานที่สองขาดช่วง ใช้ RequestID เดิมลองใหม่ คำขอที่ยังไม่ยืนยันผลเก็บไว้ในเบราว์เซอร์จนสำเร็จ การดาวน์โหลด PNG ซ้ำเป็นการอ่านข้อมูล ไม่มีการออกเลขใหม่
- ควรใช้ระบบใหม่เป็นช่องทางออกใบเสร็จหลังเริ่มใช้งาน เพื่อไม่รับเงินรายการเดียวกันผ่านสองระบบ
- PNG ใช้โลโก้จริงที่ให้มา และยังไม่มีลายเซ็นหรือตราประทับ เพราะไฟล์ source code ที่แนบเดิมว่าง จึงไม่ได้ดึงสินทรัพย์เหล่านี้จากโค้ดเก่า
- ฟอร์มหน้าเว็บรุ่นนี้เพิ่มรายรับ/รายจ่ายและออกใบเสร็จได้ ส่วนการแก้ไข/ยกเลิกใบเสร็จและการคืนเงินยังไม่มีในหน้าเว็บ
